# PUA Gaussian Splat experiment

This directory is intentionally empty of real-place imagery.

The experimental Windows build can render an EH15 Gaussian Splat visual layer when a
licensed, correctly georeferenced asset is supplied as `eh15_2bz.sog`. OpenStreetMap
continues to provide road/footprint/collision truth. A splat is visual evidence, not
surveyed geometry.

Do not put Google Maps/Street View captures or Alan's private room photographs here.
Only add imagery with appropriate reuse rights and record its source, capture date,
licence, coordinate reference/origin, orientation and scale.

The first CI probe uses the upstream GDGS sample only in an isolated renderer smoke
test. It is never packaged or presented as Edinburgh.
