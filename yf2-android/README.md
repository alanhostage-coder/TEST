# YF/2 Android

Clean-room Android rebuild inspired by the workflow of the supplied legacy sampler, with an original industrial hardware-style interface.

## v0.1 first playable build
- 48 kHz explicit stereo AudioTrack engine
- constant-power panning and mono-check
- 8 playable roles, 8×16 sequencer
- four procedural factory palettes labelled 909 / 707 / AMEN / 303
- role-aware random bank mixer
- shuffle, tempo, macro drive/filter/delay/space
- no original Yellofier audio, code or artwork redistributed

The factory palettes are original procedural approximations in this build. Verified redistribution-friendly third-party sample packs can be added as separate bank manifests once licensing is confirmed.
