# GMPI — Graphical Meat Proxy Interface

**Coined by Alan Parley on 7 September 2026.**

## Definition

A **Graphical Meat Proxy Interface (GMPI)** is the transitional state in which an AI system understands what needs to be done, but the software it must interact with still presents a graphical user interface built for a human operator. The human therefore acts as the physical proxy between the AI and the software: clicking, typing, copying, approving, moving data, and carrying out actions that the AI has already determined.

In short:

> **The AI thinks. The software waits for clicks. The human supplies the meat.**

## The progression

**CLI → GUI → GMPI → machine-to-machine / agent-to-agent**

- **CLI** — the human communicates with the machine through commands.
- **GUI** — the human operates software through visual controls.
- **GMPI** — the AI understands the task, but the human still operates the GUI on its behalf.
- **Post-GMPI** — software, APIs and agents interact directly, with the human moving toward oversight, approval or absence from the execution loop.
